# Casa da Monique · PRESERA

Protótipo local, responsivo, em português europeu. Abrir `index.html` no navegador.

Inclui painel Hoje, registo de preparação de aulas, pós-aula, conteúdos com aprovação, onboarding e entregas PRESERA. Os dados persistem **apenas no localStorage do navegador**: não existe login, base de dados, envio de emails, integração Google Drive, publicação automática ou acesso multiutilizador. Não usar dados pessoais reais de alunos ou clientes nesta demonstração.

O Scanner de Conteúdos definitivo e as inteligências da Monique não foram inventados: aguardam especificação e implementação. O calendário de três meses é uma proposta operacional, não um contrato. A versão visual aprovada da Casa da Monique ainda não foi recuperada deste repositório.

Para produção: obter código/design aprovado, confirmar proposta e entregáveis, implementar autenticação e permissões por cliente, base de dados, histórico de aprovações e testes de segurança antes de publicar dados reais.
